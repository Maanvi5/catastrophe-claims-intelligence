# User Stories

## Prepare

### US-01 — Understand event exposure
As a catastrophe claims manager, I want to see which parts of my portfolio may be affected by an upcoming weather event so that I can prepare my team.

**Acceptance criteria**
- Show affected geography
- Show number of exposed properties
- Show event severity
- Allow the user to drill into affected areas

### US-02 — Plan claims capacity
As a catastrophe claims manager, I want to see where potential claims are concentrated so that I can plan claims resources.

**Acceptance criteria**
- Show expected claim volume by area
- Show expected severity by area
- Highlight areas with higher expected workload

## Triage

### US-03 — Prioritise claims
As a catastrophe claims manager, I want to identify claims that may need deeper assessment so that my team can focus its limited capacity.

**Acceptance criteria**
- Show claims in a sortable queue
- Show claim priority
- Allow filtering by severity, amount, asset and location

### US-04 — Understand why a claim is prioritised
As a claims manager, I want to see the evidence behind a claim's priority so that I can trust or challenge the recommendation.

**Acceptance criteria**
- Show relevant claim information
- Show event/environmental context
- Show the factors behind the recommendation

### US-05 — Choose a handling path
As a claims manager, I want to see a suggested handling path so that I can decide whether a claim needs remote, desk, field or specialist assessment.

**Acceptance criteria**
- Show one recommended handling path
- Show the reason for the recommendation
- Allow the user to override it

### US-06 — Move from event to claim
As a claims manager, I want to move from the overall event view to individual claims so that I can go from understanding the catastrophe to taking action.

**Acceptance criteria**
- Select an affected area
- View relevant claims
- Open an individual claim
